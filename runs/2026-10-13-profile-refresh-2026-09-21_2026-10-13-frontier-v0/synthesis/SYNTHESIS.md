# Agents can operate more of the loop; operators inherit the seams

As of 2026-10-13. Window: 2026-09-21..2026-10-13, inclusive, UTC.
Scope: all 22 watched-harness profiles dated 2026-10-13.

Agents gained more of the work around a coding task: [native tool integration in Pi](https://github.com/earendil-works/pi/commit/8562bcf66a8eeefdf75ddd231ca9d7aa7d64f86e), [programmable plan review in OMP](https://github.com/can1357/oh-my-pi/blob/v18.10.4/docs/extensions.md#L555-L560), and [vendor-described deployment monitoring in Cursor](https://cursor.com/changelog/rollouts-and-security-reviewer). The shared movement is a larger agent-operated workflow, with authority and state increasingly decided outside the visible prompt. The operator's job moves toward admitting the right processes, binding consent to the actual effect, and checking completed outcomes.

## The runtime can move behind a pinned command

Codex made the terminal a client of a [shared background server by default for eligible interactive launches from 0.157.0](https://github.com/openai/codex/releases/tag/rust-v0.157.0). At stable 0.162.1, an eligible npm/Homebrew-seeded daemon can [update independently while leaving the CLI command alone](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/app-server-daemon/README.md#L48-L68). Its [clients share the environment retained at daemon startup](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/app-server-daemon/README.md#L22-L55). A fixed package version and a newly scrubbed terminal therefore do not describe everything the interactive session runs.

Record the CLI and daemon versions, govern the daemon updater, and restart after changing its settings. A restart does not downgrade an advanced daemon. The [explicit standalone-release pin and codex exec path have different behavior](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/app-server-daemon/README.md). This matters to Agent Flywheel because its [fresh NTM configuration launches interactive Codex](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/blob/v0.10.0/install.sh#L9748-L9765); an assembly hold does not itself govern that native server updater. That is a source-derived composition consequence, not an observed Flywheel hold failure.

Dependency resolution supplies another moving part. Flue 2.3.0 [admits Pi libraries at ^1.1.0](https://github.com/withastro/flue/blob/v2.3.0/packages/runtime/package.json), including a fresh 1.2.0 resolution. heypi's optional just-bash runtime [passes an upstream createExclusive method through its read-only skills proxy](https://github.com/hunvreus/heypi/blob/436da22ceab0bc4e2db133e8626649b4bf76286d/packages/heypi-runtime-just-bash/src/index.ts#L26-L64). With mktemp available and writable staged skills, the path permits empty entries inside that mount. Existing locks can differ; the [documented heypi scaffold selects Docker](https://github.com/hunvreus/heypi/blob/436da22ceab0bc4e2db133e8626649b4bf76286d/examples/codex-tag/index.ts#L7-L35). An unchanged wrapper can receive useful capability and lose a handwritten assumption through the same dependency range.

Release acceptance becomes part of that inventory. OpenHands [replaced the crash-looping 1.27.0 Docker image with 1.27.1 and added a boot gate](https://github.com/OpenHands/OpenHands/pull/18343). Flue [repairs runtime behavior in 2.3.0](https://github.com/withastro/flue/blob/v2.3.0/CHANGELOG.md) while [removing public release machinery and 27 test files](https://github.com/withastro/flue/commit/95a8c86244557e4c257b0fbd7eef2481de2c2150); its [2.3.0 registry record lacks the provenance carried by 2.2.2](https://registry.npmjs.org/@flue%2Fruntime/2.3.0). The older attested release lacks the new repairs. A deployment policy has to resolve that trade explicitly.

## Native interfaces absorb specific adapter work

Pi [0.99.0 brings MCP and codemode into the coding CLI](https://github.com/earendil-works/pi/commit/8562bcf66a8eeefdf75ddd231ca9d7aa7d64f86e). Codex 0.162.0 adds [policy-filtered ranked tool discovery](https://github.com/openai/codex/commit/4d15794336668d6098c0e36eb8e96cbbbfdb1d2d) and [settlement-order result helpers](https://github.com/openai/codex/commit/28a264fbc766a59f2b550b8318f88e4a4b8dffe1). Eve lets another harness [call eligible authored tools over opt-in MCP without a model turn](https://github.com/vercel/eve/blob/eve%400.79.0/docs/channels/mcp.mdx#L216-L346). A private bridge, catalog scanner or promise helper doing only those jobs now has a native alternative.

Instruction portability also improves: Claude Code [2.1.281 extends AGENTS.md support across providers and telemetry-off sessions](https://github.com/anthropics/claude-code/blob/2301018b1f61/CHANGELOG.md?plain=1#L1477), and Copilot CLI [1.0.89 reads .claude/rules](https://github.com/github/copilot-cli/blob/a3f560eca2c0/changelog.md?plain=1#L123). Retire a forwarding shim only after all relevant pins support the loader. Claude's [CLAUDE.local.md precedence and combined-loader choice](https://code.claude.com/docs/en/memory#project-instructions) still matter.

The admission work remains concrete. Pi's [stdio servers inherit the harness environment](https://github.com/earendil-works/pi/blob/v1.2.0/packages/mcp/src/transports/stdio.ts#L94); sandboxing only bash leaves those processes elsewhere. Its [classifier/image model operations bypass individual tool-call hooks](https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/src/extensions/codemode/execute.ts#L740-L751), although the enclosing script can be rejected. Codex discovery requires a supporting model and a default-off flag. Eve publication is opt-in and returns approval_required for a call needing a person. Common transport saves integration work; credentials, callable sets and policy still need their own owner.

## Setup and plans become work software can perform

Gemini [0.63.0 tells headless planning to proceed to implementation](https://github.com/google-gemini/gemini-cli/blob/v0.64.0/packages/core/src/prompts/snippets.ts#L602-L615), using an [exit-to-YOLO path that already existed](https://github.com/google-gemini/gemini-cli/blob/v0.62.0/packages/core/src/tools/exit-plan-mode.ts#L210-L268). OMP [18.10.4 lets an extension revise a plan, answer its review and choose an execution tier](https://github.com/can1357/oh-my-pi/blob/v18.10.4/docs/extensions.md#L555-L560). OpenHands [lets an agent fill an automation form](https://github.com/OpenHands/OpenHands/pull/17201) and [persist and test the draft before creation](https://github.com/OpenHands/OpenHands/pull/17242). These replace different handoffs, so the retained checkpoint differs too.

For Gemini, plan-only work needs an independently enforced boundary. For OMP, admitting an extension can delegate the plan decision; downstream tool policy still applies. For OpenHands, the person reviews trigger, schedule and profile before authorizing future work under the creator's identity. The gain is less duplicate entry and navigation. The judgment about what should run remains deliberate.

Configuration is also agent work. OpenClaw [9.7 supports requested configuration and credential changes through chat](https://github.com/openclaw/openclaw/blob/v2026.9.7/CHANGELOG/2026.9.7.md). Agent Zero [2.13 exposes messaging commands for plugin and profile-permission administration](https://github.com/agent0ai/agent-zero/commit/17033d277e4a39a99865455d87e4b0719bc3bf0f). Paperclip [2026.1012.0 gives newly activated standard agents fourteen grants](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/server/src/services/agent-permissions.ts#L3-L28), with [explicit tools:use checked before tool profiles after earlier policy checks](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/server/src/services/tool-access-policy.ts#L1466-L1480). Sender admission, effective run permissions and grant scope now decide who can configure the environment.

Cursor supplies the larger strategic complication. Its vendor-described [Rollouts workflow extends work into deployment telemetry and repair handoff](https://cursor.com/changelog/rollouts-and-security-reviewer), retaining human merge and rollback. The [13 October Origin marketplace launch](https://web.archive.org/web/20261013185441/https://cursor.com/changelog/origin-app-marketplace) adds installation-token integrations, webhooks and reviews. Provider expansion reaches beyond the reasoning loop. An independent operating layer has to earn its value through portable state, authority and outcomes; the surrounding environment is not automatically sheltered from absorption.

## Approval has to bind an action, an identity and a moment

Eve [0.78.0 stops approved calls borrowing the approver's credentials](https://github.com/vercel/eve/commit/9559de83b65e89c24172c2b9c1a80382033556aa). Stable 0.79.0 still accepts a queued approve reply sent before its later prompt; the [admission-sequence repair is only on cutoff main](https://github.com/vercel/eve/commit/0dea0ded869be7db30ae90ed8072d29e6e57df61). Keep consequential effects off that affected path until a containing release passes the exact sequence. Fixing execution identity does not establish intention to a request that did not yet exist.

OpenClaw's stable 2026.10.3 and extended-stable 2026.8.35 can apply a hook replacement after inline approval; [beta.3 binds approval to final replacement arguments](https://github.com/openclaw/openclaw/blob/v2026.10.5-beta.3/src/agents/agent-tools.before-tool-call.policy.ts#L291-L436). Claude's [released mod/guard design](https://github.com/anthropics/claude-code/blob/2301018b1f61/mods/sec-default/hooks/register.ts#L67-L114) places admitted plugin code in the permission chain, where a mod approval can skip the classifier. These are different mechanisms. Each makes the visible approval an incomplete description of the eventual effect.

There is genuine progress in supervising decisions. Codex [0.158.0 exports completed synchronous reviewer assessments through opt-in OTLP](https://github.com/openai/codex/commit/30758e5c77c14e6ddcc53a6c7407a477fed4ac76), excluding cached V2 approvals. Copilot [adds a decision-source trail and managed Manual Approval controls](https://github.com/github/copilot-cli/blob/a3f560eca2c0/changelog.md?plain=1#L11). Temporal's [0.5.0 preview adds argument-aware auto decisions](https://github.com/temporal-community/temporal-agent-harness/pull/142), while [remembered tool names can bypass that evaluator](https://github.com/temporal-community/temporal-agent-harness/blob/04a49d1b037de46da2cba31676d2aa2f4c59118f/temporal_agent_harness/harness/agent_protocol/agent_interface.py#L455-L469). Admission, criteria and sampled outcomes become a supervision job of their own.

Some improvements correctly retain a stop. Hermes [0.21.7 makes the unattended Gateway branch consult the configured policy before the guardian](https://github.com/NousResearch/hermes-agent/blob/v0.21.7/tools/approval.py#L910-L942). A formerly approved command can now be denied. Copilot's [generally available local sandbox remains default-off and needs explicit enablement](https://github.com/github/docs/blob/602021b0ba16/content/copilot/how-tos/cloud-and-local-sandboxes/using-local-sandboxing.md). Stronger boundaries and broader capability can advance together.

## Deletion earns its meaning from what disappeared

Flue [2.3.0 deletes its Claude-ID rewrite](https://github.com/withastro/flue/blob/v2.3.0/packages/runtime/src/runtime/providers.ts#L31-L33) after Pi fixes the catalog. That exact local patch stopped earning its place. Eve [removes default todo and makes ask_question opt-in](https://github.com/vercel/eve/commit/60998d606bfceb4ab367de869d73769065eadd04). Paperclip [cuts selected role/planning text without a completed provider-run comparison](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/doc/plans/2026-10-05-plan-task-guidance.md#L44-L85), while its [shared coordination skill grows from 7,626 to 8,584 words](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/skills/paperclip/SKILL.md), compared with [the baseline](https://github.com/paperclipai/paperclip/blob/v2026.916.1/skills/paperclip/SKILL.md). Procedure was redistributed; equal quality and less human work were not measured.

Hermes's [tirith removal in 0.21.6 records a different trade](https://github.com/NousResearch/hermes-agent/commit/911da42e9e03ba8594ab2af5dfd1e50e7e721e3e): the author's small corpus goes from 12/24 everyday flags to 5/24, and 14/16 attack catches to 13/16 with core alone. Those results were not independently reproduced. Cursor [attributes prompt reduction to better models in a 23 September engineering post](https://cursor.com/blog/improved-token-efficiency), describing preceding months and vendor A/B measurements. A report published this window does not date every underlying deletion to it.

Specialized loop engineering also has contrary evidence worth keeping. Unreal's [22 September vendor tables](https://web.archive.org/web/20260922183130/https://unreallabs.ai/blog/unreal-agent/) and [linked runs](https://hub.harborframework.com/jobs/27133053-2015-46f3-8c72-6b6910859da6) support a lower aggregate input-token direction against historical Codex and Pi configurations. Missing inference cost and unidentified Unreal builds prevent a current-release dollar-saving conclusion. The result earns a matched test of today's installed versions, rather than dismissal of harness engineering.

[Bitter Lesson Maxing](https://frontier.bitter.sh/bitter-lesson/) means building where improving general agents compound value. This window supports retiring exact adapters and patches when a native primitive covers them; it leaves specialized authorization, recovery and evaluation useful. [Amdahl Maxing](https://frontier.bitter.sh/amdahls-law/) means spending scarce human attention where judgment changes the outcome. Here the likely savings are repetitive handoffs; the new work is configuring authority, qualifying upgrades and reviewing exceptions. No supplied study measures net human attention or accepted company output across these 22 tools.

## Human attention moves to admission, exceptions and outcomes

The attention shift below is an inference from the mechanisms above, not a measured time saving.

| Work now available to software | Retained human decision | Concrete acceptance work |
| --- | --- | --- |
| Native discovery and tool composition | Which servers, extensions and credentials are admitted | Inspect Pi stdio environments and codemode model spend; verify Codex's feature/model prerequisites. |
| Plans, setup and future-job forms | Who may configure the environment or answer its review | Check sender admission, new-agent grants, plan callbacks and the automation creator's identity. |
| Automatic permission decisions | Which effects need accountable review | Bind exact arguments, requester credentials and reply timing; sample the decision trail. |
| Runtime-owned continuation | Which state and effects survive retry or migration | Test old Temporal history cutovers; reconcile uncertain cancellations; make paid effects idempotent. |
| Faster upgrade delivery | Which actual deployment is qualified | Inventory CLI, daemon, child versions, dependency locks, updater settings and release acceptance. |

Agent Flywheel makes the accidental serial queue visible. The maintainer [reports a completed 175-run fail-closed publication streak](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/issues/433#issuecomment-6131196991); a [main-only repair lets unrelated eligible repins proceed while one external-byte authorization stays pending](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/commit/2354efbaa6b355b93a53d6052fcc8f56950893b1). Preserve human authorization of new external bytes. Remove the coupling that made every other update wait.

The useful measurement is a fixed workload at recorded runtime/configuration pairs: accepted outcomes, failures, spend, human setup, review, maintenance and rework. Counting agents, approvals or tokens alone cannot settle whether the whole workflow improved.
