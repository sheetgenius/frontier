## Judgment

The refresh substantially improves release truth. All 22 drafts identify a dated installation target, and most distinguish shipped code from enabled functionality. The largest remaining utility problems are narrower: a defect in an optional runtime can look like the ordinary installation; an installation command can precede the conditions that make it an acceptable experiment; a migration requirement can sit far below the upgrade recommendation; and genuine gains can be presented mainly as another permission problem.

The drafts generally hold positive claims to primary receipts. This lens found no basis to turn their capability additions into measured model improvement, net attention savings, or whole-company throughput. The fix is selection and placement, with a few concrete scope and channel corrections. It is not a quota of cheerful sentences. In particular, Unreal's linked vendor records support a narrower positive result than its advertised dollar savings, and heypi has compatible upstream recovery improvements even though heypi itself did not release. Report those supported results without promoting them into current-product performance guarantees.

Authority: [EDITORIAL.md's decision packet](../../../EDITORIAL.md#the-decision-packet), utility pass, both halves, and profile bar; [METHOD.md's capability lane](../../../METHOD.md#the-capability-lane) and minimum signal packet; [THESIS.md's reader contract](../../../THESIS.md#the-reader-contract). The relevant editorial lines are 96-111, 124-131 and 297-339. These profiles need a dated operating decision, not an accumulated inventory that gives every observation the same weight.

This was a source-level cold read, not a timed reader study. I read all 22 write-up memos in full, all 22 draft bodies and their identity/channel metadata, each baseline's channel advice, and targeted baseline, corrected-harvest and crosscheck material for the questions below. The corrected harvest is the record of fact; a crosscheck can explain its correction but does not license restoring a rejected original claim. No upstream code, installer, runtime, test or site build was executed. No git mutation was performed. This file is the only authored artifact.

## Constraints on the final drafting pass

1. Keep the October 13 posture. October 14 registry reads corroborate available versions; they do not reconstruct a mutable pointer's history. Preserve especially Cursor's morning-only CLI observation, Hermes's UTC v0.22.0 boundary and the unknown closing Grok alpha pointer.
2. Do not flatten feature state into package state. A tagged release can contain default-off code; a non-prerelease release can still be a beta product; a prerelease tree can contain a script without supplying a qualified installer. These distinctions are already mostly correct and should survive compression.
3. Put compatibility before the upgrade for the audience it affects: Paperclip writer drain, OpenHands backend floor, Temporal Code Mode workers/histories, OMP machine output, Unreal state/API migration, and heypi's removed migration path. Do not make every other reader carry all those integration details.
4. Preserve gain and cost in the same decision. New forms, catalogs, remote settings, durable waits, native tool publication and deploy monitoring are available capabilities. Their existence does not establish fewer human hours, better reasoning, universal containment or exactly-once effects.
5. Do not add a peer just to manufacture synthesis. These edits can be supported by each corrected source packet. Cross-provider defaults and runtime results still need their own receipts. In particular, Pi Durable is not installed heypi, a DeepSeek model route is not the DeepSeek Harness product, and a named child CLI does not restore a sandbox its invocation bypasses.
6. Retain meaningful uncertainty and its settling evidence. A named containing tag, a replay test, a protected-route denial, an installed-package inventory or an attributed run can change a decision. A calendar reminder, an issue closure or a general request to re-audit cannot.
