# The lens across the watchlist

Posture: 2026-10-13. Window: 2026-09-21 through 2026-10-13, inclusive, UTC.
Analysis performed: 2026-10-14.
Run: 2026-10-13-profile-refresh-2026-09-21_2026-10-13-frontier-v0.

## The read

The clearest movement is a larger agent-operated workflow: configuring the environment, discovering and composing tools, continuing background work, and preparing decisions that used to require a person to move between interfaces. Narrow adapters and continuation wrappers have credible native replacements. The record does not establish a new general reasoning ability or a net reduction in human attention across these 22 sources.

The attention consequence is an architectural inference from the changed mechanisms: more decisions can be made once at admission, configuration or launch, while review concentrates on authority, outcomes and exceptions. The receipts also show new integration and upgrade work. Removing prompts or code is an event; improving verified throughput is a result that still needs measurement.

Six patterns earn a cross-provider reading. Each has at least two watched sources with pinned primary receipts. Older behavior rechecked this window, retrospective vendor reports, opt-in features and unreleased repairs are identified separately. The patterns are not a ranking or a claim that providers have equivalent controls.

## 1. Common tool and instruction interfaces absorb private adapters

**What moved.** Pi reversed its no-MCP posture: [0.99.0 brought MCP and codemode into the CLI on 29 September](https://github.com/earendil-works/pi/commit/8562bcf66a8eeefdf75ddd231ca9d7aa7d64f86e). Codex [0.162.0 added policy-filtered ranked tool discovery](https://github.com/openai/codex/commit/4d15794336668d6098c0e36eb8e96cbbbfdb1d2d) and [settlement-order result helpers](https://github.com/openai/codex/commit/28a264fbc766a59f2b550b8318f88e4a4b8dffe1). Eve [0.72.0/0.73.0 made eligible authored tools and skills available through MCP](https://github.com/vercel/eve/blob/eve%400.79.0/docs/channels/mcp.mdx?plain=1#L216-L346), with tool invocation outside a model turn. Together these expand what an existing agent can reach and compose without a private bridge.

The instruction side has a similarly concrete join. Claude Code [2.1.281 extended AGENTS.md loading across providers and telemetry-off sessions](https://github.com/anthropics/claude-code/blob/2301018b1f61/CHANGELOG.md?plain=1#L1477). Copilot CLI [1.0.89 began reading .claude/rules files](https://github.com/github/copilot-cli/blob/a3f560eca2c0/changelog.md?plain=1#L123). A forwarding file or rule translator has less reason to exist once the receiving harness accepts the source convention. That does not establish identical precedence or trust timing.

**What can be retired.** A private Pi-to-MCP adapter, a catalog scanner doing only native search, a promise-settlement helper doing only the new Codex operation, and a CLAUDE.md forwarding shim for an all-current fleet are specific candidates. Claude's default loader still lets CLAUDE.local.md suppress AGENTS.md; selecting the documented combined loader is a prerequisite where local notes remain. Do not generalize these deletions to all integration or governance code.

**Where attention goes.** Server and tool inventory, credentials, extension admission, and verification of nested dispatch replace some plumbing work. The defaults differ materially: Codex search needs model support and a default-off flag; Pi can activate codemode through an enabled MCP server's default exposure; Eve publication is opt-in. Pi's [stdio servers inherit the harness environment](https://github.com/earendil-works/pi/blob/v1.2.0/packages/mcp/src/transports/stdio.ts#L94), and its [script model operations bypass individual tool-call hooks](https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/src/extensions/codemode/execute.ts#L740-L751). Eve [returns approval_required for a published call needing a person](https://github.com/vercel/eve/blob/eve%400.79.0/docs/channels/mcp.mdx?plain=1#L242), instead of creating a durable conversation around that call.

**What cuts against the thesis.** General interfaces make authority engineering more valuable. A common tool name, standard transport or hidden declaration is insufficient evidence that a call is denied. No matched workload here establishes how much adapter removal saves in review time or task cost.

## 2. Setup and plan review become work that software can operate

**What moved.** Gemini CLI [0.63.0 directs headless plans to proceed to implementation](https://github.com/google-gemini/gemini-cli/blob/v0.64.0/packages/core/src/prompts/snippets.ts#L602-L615). Its [exit-to-YOLO transition already existed](https://github.com/google-gemini/gemini-cli/blob/v0.62.0/packages/core/src/tools/exit-plan-mode.ts#L210-L268); the in-window change is the instruction to use it. OMP [18.10.4 lets extensions revise a plan and answer its review](https://github.com/can1357/oh-my-pi/blob/v18.10.4/docs/extensions.md#L555-L560). OpenHands [v1.27.0 lets an agent fill an automation form](https://github.com/OpenHands/OpenHands/pull/17201), with [persistent drafts and tests before creation](https://github.com/OpenHands/OpenHands/pull/17242). These move different portions of the path from intent to execution into software.

Configuration joins that movement. OpenClaw [2026.9.7 added owner-requested credential, configuration and skill work through chat](https://github.com/openclaw/openclaw/blob/v2026.9.7/CHANGELOG/2026.9.7.md). Agent Zero [v2.13 exposed plugin toggles and profile-permission editing to configured messaging users](https://github.com/agent0ai/agent-zero/commit/17033d277e4a39a99865455d87e4b0719bc3bf0f). Paperclip [v2026.1012.0 seeds fourteen grants into new activated standard agents](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/server/src/services/agent-permissions.ts#L3-L28), including tool use and configuration. Existing agents are not backfilled, and low-trust and built-in agents are excluded.

**The meaningful divergence.** These are not six versions of the same human checkpoint. Gemini headless planning is executable. OMP's first answering extension can make the plan choice, while downstream tool policy remains separate. OpenHands lets a person inspect the trigger, schedule, profile and test result before accepting work that runs as its creator. OpenClaw [uses the requesting run's effective permission mode](https://github.com/openclaw/openclaw/blob/v2026.10.3/docs/cli/openclaw.md#L120-L143); Full Access and automatic delegated application predate the window. Agent Zero's editor persists a non-Default profile in [the active project scope, or global scope without a project](https://github.com/agent0ai/agent-zero/blob/v2.14/plugins/_agent_editor/helpers/editor.py#L742-L781), while plugin toggles are instance-wide. Paperclip's [broad tools:use grant is evaluated before a tool profile, after earlier policy checks](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/server/src/services/tool-access-policy.ts#L1466-L1480).

**What can be retired.** A wrapper whose sole job is to tell Gemini to continue after its plan, manual form construction covered by the OpenHands tool, and routine dashboard detours covered by OpenClaw chat setup are candidates. A path-specific prompt refusal is a weak control where the same operation remains available through shell and file tools. This is not a reason to delete an independent write boundary or an accountable human approval.

**Where attention goes.** Decide the permitted environment before the run, who may administer it, who may answer a review, and what successful completion means. The useful reduction is duplicate entry and predictable navigation; the retained judgment is authority. No time saving or completion-rate improvement was measured.

**What cuts against the thesis.** Making setup delegable can widen authority faster than it reduces work. Google's own [issue-triage and dedup workflow hardening removes shell tools and parses model output in ordinary code](https://github.com/google-gemini/gemini-cli/commit/2fe7c2d3f065dc40ad573d50b2091116f8a4aa18). That is a narrower operating task, not the general CLI default, and a useful example of obtaining a better system by keeping the agent's authority small.

## 3. Automated approval creates a supervision job of its own

**What moved.** Codex [0.158.0 added opt-in OTLP export of completed synchronous reviewer assessments](https://github.com/openai/codex/commit/30758e5c77c14e6ddcc53a6c7407a477fed4ac76), alongside reviewer policy controls. Copilot CLI [1.0.94 lets managed policy require Manual Approval](https://github.com/github/copilot-cli/blob/a3f560eca2c0/changelog.md?plain=1#L29), and [1.0.96 identifies whether a person, Assisted Permissions, policy or unattended fallback made the decision](https://github.com/github/copilot-cli/blob/a3f560eca2c0/changelog.md?plain=1#L11). Temporal's installable [0.5.0 preview adds opt-in, argument-aware auto decisions](https://github.com/temporal-community/temporal-agent-harness/pull/142), with evaluator errors or unusable results escalating. These are native mechanisms for concentrating supervision around policy and exceptions.

**The boundaries matter more than the shared label.** Codex's older reviewer is default-on, [Guardian V2 remains default-off](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/features/src/lib.rs#L1763-L1808), and the OTLP export excludes cached V2 approvals. Copilot's inspected receipts do not name the managed disabling key or define unattended fallback. Temporal's Jev thresholds belong to that evaluator, not every custom evaluator; [a remembered bare tool name bypasses auto mode while it remains allowed](https://github.com/temporal-community/temporal-agent-harness/blob/04a49d1b037de46da2cba31676d2aa2f4c59118f/temporal_agent_harness/harness/agent_protocol/agent_interface.py#L455-L469). Its default jev-latest also creates a calibration/version decision.

Routing can defeat a claimed human or model stop. Claude Code's [documented permission chain lets mods approve before the auto classifier](https://code.claude.com/docs/en/permissions#extend-permissions-with-hooks); the [pinned guard source](https://github.com/anthropics/claude-code/blob/2301018b1f61/mods/sec-default/hooks/register.ts#L67-L114) and binary checks in its packet settle where the guard loads. Hermes [v0.21.7 repairs the running gateway branch that bypassed unattended policy](https://github.com/NousResearch/hermes-agent/commit/8918717b1ad2b52d1389756a3581a9860b98397b). A job the model formerly approved can now be blocked by the configured deny. That is progress through a stronger retained gate.

**What must survive fewer prompts.** Eve [0.78.0 binds approved execution to the requester instead of lending the approver's credentials](https://github.com/vercel/eve/commit/9559de83b65e89c24172c2b9c1a80382033556aa). Yet the [queued-text consent repair is main-only at the cutoff](https://github.com/vercel/eve/commit/0dea0ded869be7db30ae90ed8072d29e6e57df61). OpenClaw [binds inline approval to hook-rewritten final arguments only in the beta repair](https://github.com/openclaw/openclaw/commit/34d07e7b0dc1b5f0ed54de67a9647d9e6b8c23de), absent from stable 2026.10.3 and extended-stable 2026.8.35. The common invariant is an attributable decision about the particular effect, with execution identity and enforceable policy kept separate.

**Where attention goes.** Write criteria, admit the code that may answer, pin evaluators where possible, sample decisions, and handle exceptions. Keep manual review for consequential effects when that is the accountability design. A native judge can replace a narrow private classifier; these receipts do not establish its accuracy or savings, much less the obsolescence of deterministic authorization.

**What cuts against the thesis.** Better agents are increasing the importance of specialized policy code and exact dispatch order. More autonomy is not always the fix: Hermes now obeys a deny, Copilot can retain Manual Approval, and Codex adds [review for meaningful stdin sent to an already escalated terminal](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/core/src/unified_exec/stdin_approval.rs#L190-L251). These are deliberate boundaries. No packet establishes that judge supervision costs less human time overall.

## 4. Continuation becomes runtime machinery, with migration and effect costs

**What moved.** Temporal [0.6.0 moves Code Mode stepping into the workflow](https://github.com/temporal-community/temporal-agent-harness/blob/04a49d1b037de46da2cba31676d2aa2f4c59118f/temporal_agent_harness/harness/code_mode/monty_stepper.py#L9-L58), replacing the old batch-activity snapshot transport. Scripts get workflow time and durable timers; a suspended tool or human wait holds no interpreter subprocess. Flue [2.2.0 documents exact-argument approvals that end the response and resume from application state](https://github.com/withastro/flue/blob/v2.3.0/apps/docs/src/content/docs/guide/tools.md#L228-L433). Flue's contribution is a documented composition of existing primitives, not a newly built-in approval service.

Grok [1.0.51 makes headless runs wait for background goals](https://storage.googleapis.com/grok-build-public-artifacts/cli/changelogs/1.0.51.external.md?generation=1791580490548989), available on stable 1.0.52. Unreal [v0.3.1 restores restart deduplication for every input kind](https://github.com/unreallabsai/unreal-agent/commit/31f4fdadc54dd5061ae33959bc151d1b649c3a31). Pi's [separately installed experimental Durable runtime](https://github.com/earendil-works/pi/blob/v1.2.0/packages/durable/README.md) offers interrupted-turn recovery; it does not replace the coding CLI and does not reach heypi through its old SDK range. Hermes [v0.21.7 preserves route-appropriate signed reasoning on resume](https://github.com/NousResearch/hermes-agent/commit/79b45d1647f6b5680768d851c4c406e8cc550a1e). These solve different continuation failures, not one interchangeable durability contract.

**What can be retired.** A completion poller covered by Grok's wait, duplicate-input bookkeeping covered by Unreal's inbox, and Temporal's former batch-snapshot transport have concrete replacements. Flue lets a person leave a running response's timeout budget. None of these removes application-owned authentication, approval expiry or side-effect idempotency.

**Where attention goes.** Review resumed outcomes and uncertain effects; govern history cutovers and compatible workers. Temporal [pins Monty 1.0.0](https://github.com/temporal-community/temporal-agent-harness/blob/04a49d1b037de46da2cba31676d2aa2f4c59118f/pyproject.toml#L79-L84), and [the relocation has no established old-history compatibility path](https://github.com/temporal-community/temporal-agent-harness/pull/167). Replay risk is inferred, not reproduced failure; blind reset is not a demonstrated remedy. Grok needs a background wait timeout. Unreal's [nil Add/Cancel return means acceptance, with operational failures on Updates](https://github.com/unreallabsai/unreal-agent/blob/v0.3.1/harness/operation/local_manager.go#L75-L165), including unknown remote cancellation outcomes.

**What cuts against the thesis.** Special-purpose workflow and recovery engineering remains useful. Durable history does not imply one execution of a paid effect. Grok [1.0.52 repairs one repeated HTTP MCP execution path](https://storage.googleapis.com/grok-build-public-artifacts/cli/changelogs/1.0.52.external.md?generation=1791825995316875), without establishing universal exactly-once delivery. DeepSeek's [alpha.2 deletes Team outbox retention, retries and resend deduplication](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/packages/experimental/agent-team/README.md#L68-L70). That simplification returns failed-send recovery to callers. Its [rc removal of the default three-wake cap](https://github.com/deepseek-ai/deepseek-harness/commit/b6775f6d4f55eaa0bcac36318cd7dfc98d70195c) also permits longer unattended chains with an explicit budget/continuation trade. Less scaffolding can remove a guarantee as well as work.

## 5. Scaffolding shrank, but the reason for removal must be reported

**The actual deletions.** Paperclip [shortened selected default role and planning files](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/server/src/services/default-agent-instructions.ts#L3-L6): the CEO bundle falls from 1,893 baseline words to a selected 20-word statement, and two planning skills from 1,937 to 415 combined words. Its [live comparison record contains zero provider runs and no behavioral grade](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/doc/plans/2026-10-05-plan-task-guidance.md#L44-L85). Meanwhile the [shared coordination skill grows from 7,626 to 8,584 words](https://github.com/paperclipai/paperclip/blob/v2026.1012.0/skills/paperclip/SKILL.md), checked against [the baseline](https://github.com/paperclipai/paperclip/blob/v2026.916.1/skills/paperclip/SKILL.md). The system did not simply stop needing procedure.

Eve [0.65.0 removed default todo and made ask_question opt-in](https://github.com/vercel/eve/commit/60998d606bfceb4ab367de869d73769065eadd04); [0.76.0 replaced several discovery paths with a small catalog surface](https://github.com/vercel/eve/commit/8c55ea7c132f9a23829214bda48069d710da77fa). OMP [18.10.4 deleted its Codex Code Mode partition](https://github.com/can1357/oh-my-pi/commit/7b2bd46db7e175abc09b0d37004bf5dc8ccd0962). This is OMP's change, not an upstream Codex deletion or proof that Codex models became better. Codex itself [retired the personality feature](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/features/src/lib.rs#L1889-L1892), without a matched quality result. Its update_plan default change belongs to the previous window, not this concurrent deletion count.

**Two different causal cases.** Flue [2.3.0 directly registers the upstream provider](https://github.com/withastro/flue/blob/v2.3.0/packages/runtime/src/runtime/providers.ts#L31-L33), deleting [2.2.2's Claude model-ID rewrite](https://raw.githubusercontent.com/withastro/flue/refs/tags/@flue/runtime@2.2.2/packages/runtime/src/runtime/providers.ts). The corrected record identifies Pi's catalog repair as the reason. A transient upstream mistake stopped requiring a local patch. This is a clean absorption of adapter responsibility, without a claim about reasoning.

Hermes [removed tirith in v0.21.6 over false flags, limited coverage and installation costs](https://github.com/NousResearch/hermes-agent/commit/911da42e9e03ba8594ab2af5dfd1e50e7e721e3e), adding [two checks to its built-in detector](https://github.com/NousResearch/hermes-agent/commit/68dd9927691e66058bf2347937e7dc276ceb50cd). The removal author's small comparison reports fewer ordinary-command flags and one fewer attack caught. This is a coverage/usability trade, not proof that a better model made the scanner unnecessary. It leaves no automatically installed tirith replacement.

**The model-causation lead.** Cursor's [23 September engineering post attributes prompt and generic subagent-guidance reductions to improving models](https://cursor.com/blog/improved-token-efficiency), with vendor A/B measurements. It describes preceding months and supplies neither a build mapping nor a reproducible raw dataset. Treat it as a report published inside the window, not proof that every deletion shipped inside it or a savings forecast for a reader's system.

**What an operator should test.** Remove generic planning or exploration guidance on one matched task only after identifying what oversight it supplied. Retain accepted results, failures, tokens, spend and human corrections. Delete a catalog repair when the exact upstream defect is gone. Preserve specialized instructions where the matched result warrants them. No receipt here permits a general instruction to remove all planning, routing or evaluation code.

**What cuts against the thesis.** Unreal's [22 September vendor comparisons and linked runs](https://web.archive.org/web/20260922183130/https://unreallabs.ai/blog/unreal-agent/) support a lower aggregate input-token direction for its specialized loop. That is a real reason to test harness engineering, even though [the linked Unreal jobs omit inference cost and use builds unmapped to public tags](https://hub.harborframework.com/jobs/27133053-2015-46f3-8c72-6b6910859da6). The record does not establish v0.3.1 dollar savings or an overall quality winner. Removing an adapter can be correct while a specialized scheduler or evaluator still earns its cost.

## 6. Upgrade governance reaches beyond the top-level package

**The in-window movement.** Codex [0.157.0 makes eligible interactive launches attach to a shared background service](https://github.com/openai/codex/releases/tag/rust-v0.157.0). A seeded stable npm/Homebrew daemon package can [follow latest while leaving the CLI command fixed](https://github.com/openai/codex/blob/rust-v0.162.1/codex-rs/app-server-daemon/src/prepare_install.rs#L245-L338). It retains its startup environment. This is source-traced eligibility, not an observed fleet upgrade; explicit standalone pins and other launch paths differ, and codex exec does not use this daemon path.

Flue [2.3.0 widens its Pi dependencies to ^1.1.0](https://github.com/withastro/flue/blob/v2.3.0/packages/runtime/package.json#L87-L88), so a new resolution can bring Pi 1.2.0's behavior without a new Flue release. heypi remains an unchanged beta, but [just-bash 3.6.0 adds atomic temporary-entry creation](https://github.com/vercel-labs/just-bash/releases/tag/just-bash%403.6.0) inside its admitted range; [heypi's old read-only proxy passes the new mutator through](https://github.com/hunvreus/heypi/blob/436da22ceab0bc4e2db133e8626649b4bf76286d/packages/heypi-runtime-just-bash/src/index.ts#L26-L64). With mktemp available and writable staged skills, empty entries can be created in the nominally read-only mount. No outside-root write, overwrite or executed exploit is established.

**The rechecked counterparts.** Copilot's [CLI updater remains default-on](https://github.com/github/docs/blob/602021b0ba16/content/copilot/reference/copilot-cli-reference/cli-config-dir-reference.md?plain=1#L452-L453), Antigravity's [updater requires a separate opt-out](https://web.archive.org/web/20260918134151/https://antigravity.google/docs/cli/troubleshooting), and Grok's [version selection does not disable automatic updates](https://github.com/xai-org/grok-build/blob/2bdd1d6a6369de0e8c68132ea4539e9abd9e14a8/crates/codegen/xai-grok-pager/scripts/install.sh#L207-L345). These correct older installation advice; they are not new updater introductions this window. Codex updates a separately selected server, whereas the others replace their client binary. Do not report a single shared schedule or failure mode.

**Where attention goes.** Record client, serving process, child harness, dependency resolution, plugins, model request/response identity and updater policy for the actual entry point. Automate that inventory, then test representative denied actions and completed outcomes at the integration seam. Own a lock and a compatible upgrade path. heypi's narrow Pi range also illustrates the opposite trade: it preserves an old API while excluding new capability, and a forced override cannot supply a missing export.

Agent Flywheel makes the serial cost visible. Its [v0.10.0 installer reads a moving checksum ledger separately from its script pin](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/blob/v0.10.0/install.sh#L173-L185). A [main-only repair decouples other repins from one pending external-byte authorization](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/commit/2354efbaa6b355b93a53d6052fcc8f56950893b1). The corrected issue inventory contains 34 authorization issues, and the maintainer [reports a completed 175-run fail-closed streak](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/issues/433#issuecomment-6131196991). Human byte review remains deliberate authority; making every unrelated update wait was accidental serial work. The recovery report is attributed, and the fix is not in stable.

**What cuts against the thesis.** Upstream progress can increase integration work. A useful new filesystem primitive can invalidate a handwritten boundary, and a smaller native loop can still require precise packaging and release acceptance. ACFS's [eight passing smoke checks did not make its reported full installation pass](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/issues/427). OpenHands [added a mechanical boot gate after its 1.27.0 Docker crash loop](https://github.com/OpenHands/OpenHands/pull/18343). Neither establishes that a particular QA omission caused the failure. Automatic delivery of fixes can be useful, but faster release output and passing component checks do not establish verified end-to-end progress.

## The evidence that tests the company layer decision

The operating environment is a durable responsibility, not a reserved market. Cursor's [23 September Rollouts announcement extends work into deployment telemetry and regression handoff](https://cursor.com/changelog/rollouts-and-security-reviewer), retaining human merge and rollback. Its [13 October Origin marketplace announcement opens installation-token integrations, webhooks and reviews](https://web.archive.org/web/20261013185441/https://cursor.com/changelog/origin-app-marketplace). These are dated hosted/vendor-described capabilities, not source-verified deployments. They nevertheless cut against assuming providers will remain confined to reasoning loops while independent infrastructure is sheltered from absorption.

A separate layer has to earn its value through state, authority, verification and portability. Omnigent's [specific Databricks signer keeps credential minting outside the contained worker](https://github.com/omnigent-ai/omnigent/blob/v0.18.0/omnigent/inner/codex_worker.py#L111-L180), and [stored root policies now reach native children](https://github.com/omnigent-ai/omnigent/blob/v0.18.0/omnigent/runtime/policies/builder.py#L437-L444). Those are useful specialized mechanisms, subject to the particular executor and actual harness pair. They do not establish complete containment or that every embedded provider safeguard survives a wrapper's invocation.

The window supports retiring exact functions that a native mechanism now supplies. It supports keeping deliberate identity, spending, review and irreversible-effect gates. It does not settle whether the resulting company is faster. To settle that, compare one fixed workload at pinned runtime/configuration pairs, count accepted outcomes and failures, and include human review, setup, maintenance, recovery, rework and spend. An approval count, agent count or token reduction alone cannot answer the end-to-end question.

Record: [Cursor sections 10 and 13](../harvest/cursor.primary.md), [Omnigent sections 8 and 14](../harvest/omnigent.primary.md).
