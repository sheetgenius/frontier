## Material misses and under-promoted changes

For every tagged entry below, the named commit is absent from the preceding stable and present in the stated first stable and 0.79.0. Main-only entries are absent from 0.79.0 and present in the pinned end-of-window main snapshot. Dates below are first release dates unless explicitly called merge dates.

### M1. A later stable changed approval policy inputs, prompts, and eval reporting

**Channel: tagged-release, 0.79.0, 2026-10-13.** The omitted release adds [MCP toolAnnotations to connection approval policies](https://github.com/vercel/eve/commit/f5e5183ae40287c9c922b6b4591fb36b53950412), [input-aware approval.prompt summaries](https://github.com/vercel/eve/commit/302a4d341059d93cd6de8f5f1744eff4bf21ff6e), and [t.score with optional assertion score/threshold/passed fields](https://github.com/vercel/eve/commit/bc2be45f02269a3e3d91f02ded40699719006e01). Custom reporters must use `passed === false` as the failure test. Annotation hints are supplied by the MCP server; a readOnlyHint is not independently enforced proof of safety. Slack retains full inputs below its summary. These changes affect both approval design and eval integrations. The release also [consolidates tracing and durable trace checkpoints while retaining schema 4](https://github.com/vercel/eve/commit/76f68542dbfaa22ea44af6ceaf3e7ca59c2a020a). Read all six release bullets, not just the minor-version headline.

### M2. Queued text can approve a request that did not yet exist

**Channel: main-unreleased; merged 2026-10-13T22:38:36Z.** [0dea0ded869be7db30ae90ed8072d29e6e57df61](https://github.com/vercel/eve/commit/0dea0ded869be7db30ae90ed8072d29e6e57df61) records the queue admission sequence when a turn begins waiting and excludes earlier queued messages from answering it. In 0.79.0, a requester can send `approve` with `turnPolicy: "queue"` before a later approval prompt exists; when the turn waits, that text can settle the later request and run its tool without the person having seen that prompt. Read the pre-fix queue, fix, and regression test, plus PR #4749. The test was not executed here.

Do not describe 0.78.0 or 0.79.0 as fixing this. Test queued typed replies in the operator's authority checks and watch for a release containing this exact commit. The fix concerns pre-request queued messages; it is not proof that every timing case under the default `steer` policy is closed. This is a consent-timing defect, not evidence of approver-credential lending after 0.78.0.

### M4. Datadog eval content changed from opt-in to default export

**Channel: tagged-release, 0.69.0, 2026-10-01.** [f0a9ee199cc3ea0048d4d8c527888d888f8bade6](https://github.com/vercel/eve/commit/f0a9ee199cc3ea0048d4d8c527888d888f8bade6) enables recording eval inputs, outputs, authored expectations, errors, and assertion details by default for the configured Datadog reporter. The old docs said metadata and scores by default; the new docs say to set the respective `record*` options false to omit content. Without Datadog credentials, reporting is skipped. [Current reporter documentation](https://github.com/vercel/eve/blob/eve%400.79.0/docs/evals/reporters.mdx).

This is distinct from runtime audience-based trace capture. Operators with sensitive eval fixtures must review the reporter configuration before upgrading; the unchanged runtime table is not evidence that eval-content export stayed unchanged.

### M5. Local workflow recovery became opt-in

**Channel: tagged-release, 0.68.0, 2026-09-28.** [0ac01f6bc85d2d18e463aa9c97834ca524ad9df3](https://github.com/vercel/eve/commit/0ac01f6bc85d2d18e463aa9c97834ca524ad9df3) leaves workflows from earlier local-development invocations dormant by default. `eve dev --resume` attempts retained-snapshot recovery even across source changes; replay can perform work and then fail. Missing snapshots are cancelled, while malformed generation metadata remains dormant. This changes the concrete meaning of restart recovery in development and deserves a caveat beside the durable-execution claim. [Versioned release explanation](https://github.com/vercel/eve/releases/tag/eve%400.68.0).

### M12. Gateway-native search and stalled-model recovery

**Channel: tagged-release.** [f8ea556b508c](https://github.com/vercel/eve/commit/f8ea556b508c967ecf109287b3cdd60daf2172f6), first in 0.76.0 on 2026-10-09, lets `webSearch({ provider: "native" })` use OpenAI, Anthropic, or Gemini 3+ hosted search through AI Gateway. ### M13. Same-host connection identity fix was main-only

**Channel: main-unreleased; merged 2026-10-13T22:06:24Z.** [57d4272b7a39c6a179c7b88aff3111bafaf99b2c](https://github.com/vercel/eve/commit/57d4272b7a39c6a179c7b88aff3111bafaf99b2c) gives MCP/OpenAPI `toolResultFrom` fallback identities both URL and description.
