## Misses and material omissions

Dates below are UTC. Every change was independently checked against v0.10.0, `cloud-binaries-v1`, and the cutoff commit. "Mirror source only" means `preview-or-beta` source ancestry, not delivery of that ACFS change in the JSM/UBS assets. All later untagged fixes are `main-unreleased`. These are research candidates; the source contract's stable evidence floor must not be silently widened when updating the public profile.

### M1. Stable changed updater locking and its busy exit code

**2026-09-23; tagged-release, first stable v0.10.0.** `4501dd0a` replaces per-invoking-UID locking with a lock on the resolved target-home directory before discovery, logging, self-update or component work. Root and target-user updates of the same installation now contend; missing locking prerequisites fail closed, and a busy run returns **75**, not a successful skip. Finish older updater processes before adopting the new protocol. This changes both concurrent-update safety and automation's exit-code handling. ### M5. Root runtime permission repair had a symlink race

**2026-10-10; main-unreleased, in no tag.** `57921111` stops root from repairing modes in a runtime owned by another user. Between enumeration and chmod, that user could replace an entry with a symlink, making root alter permissions on its target; the commit gives `/tmp` losing group/other write as an example. The fix leaves repair to the runtime owner. This is a permission-change/denial-of-service mechanism, not proof of remote code execution. The affected mode-repair series was introduced after v0.10.0, so do not label stable vulnerable to this particular regression. [Patch](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/commit/57921111a17405bc709c2fdc841b5fb3d57785cc), [fixed guard](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/blob/0bf744a81c319accaa62d763bce97073ac693ef5/scripts/lib/update.sh#L3666-L3681).

## Rule checks and remaining limits

- **Receipt pins:** opened every numbered section's receipt, reading blob/tag/SHA objects locally and release/issue records through GitHub. No numbered blob receipt uses main or HEAD. Release bodies, issue comments, advisory inventories and official live pages are mutable event/current-posture sources, not immutable historical trees; where available, use the exact comment anchors and pinned code above. A compare ending at a full SHA is bounded even if it originated on main.
- **Security search:** the repository security-advisory API returned `[]`; the global GHSA ACFS-name query returned `[]`; NVD keyword searches for `agentic_coding_flywheel_setup` and `agent flywheel` returned zero. These are search results observed October 14, not a warranty of no vulnerabilities. Dependency advisories are separately identified and explained in M7. [Repository advisory surface](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup/security/advisories).
- **Marketing versus substance:** the budget remains attributed. Hosted acceptance, install duration, fleet-wide outages and historical factory outcomes remain attributed to their authors. Static source supports the configuration and gate changes, not live throughput, successful full installs, successful provider execution, or a measured reduction in human attention.
- **Social:** no social quotation is used as proof. Issue #437 contains links to social posts, but the harvest reports the issue as a user report and does not quote those posts. The paper is contextual research, not proof that the Flywheel caused repository output.
- **No silent date widening:** October 14 commits, the third mirror asset and this verifier's current checksum/HTTP observations do not become October 13 events. Commit dates are normalized to UTC here; release publication dates come from the API.
- **Unresolved acceptance:** no installer, reboot recovery, live NTM launch, plugin install, cloud-hosted session, exploit, package build, or upstream test was run. No deployment SHA was established for the live website. These boundaries remain explicit rather than being filled with the researcher's confidence rating.
