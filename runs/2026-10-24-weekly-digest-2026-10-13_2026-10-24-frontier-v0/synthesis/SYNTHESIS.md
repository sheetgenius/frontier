# More of the job can stay with the agent. Acceptance still needs an owner.

As of 2026-10-24, supported harness paths cover more context selection, delegation, waiting and recovery. Builders can retire specific pieces of duplicate plumbing, but the consequential decisions move toward initial grants, persistent state, compatibility and acceptance. Some products automate an approval; others strengthen the requirement for a person to answer it.

Window: strictly after 2026-10-13T23:59:59Z through the individual successful source reads on 2026-10-24 UTC. Profiles are dated 2026-10-24. Channel pointers below belong to those recorded reads, not the end of the UTC day. This synthesis adds no new registry observation or runtime acceptance result.

## One adapter actually threw its interpreter away

On 22 October, [pi-mcp-adapter 6.0.0 removed QuickJS, its separate script tools and its scripting skill in favor of Pi's codemode](https://github.com/nicobailon/pi-mcp-adapter/blob/v6.0.0/CHANGELOG.md). This is the cleanest continuation of the previous issue's argument about replacing private bridges with supported primitives. The capability already exists upstream; the downstream maintainer can stop carrying a second implementation.

The migration is also the story. Calls now expose their real MCP tool names to permission hooks, and a recognized Executor approval pause reaches a person rather than allowing model self-approval. Users must [port script settings and hook matchers and test proxy, deferred and scripted calls](https://github.com/nicobailon/pi-mcp-adapter/blob/v6.0.0/README.md). The deleted interpreter belongs to an optional adapter. Pi core did not delete an interpreter this week, and the deletion does not prove a gain in model intelligence or total throughput.

That is an earned case of [Bitter Lesson Maxing](https://frontier.bitter.sh/bitter-lesson/): build where improving general agents compound the advantage instead of erasing it. Here, reuse already makes a narrow custom layer unnecessary. Independent Pi supplies the primitive, which cuts against a stronger claim that only model providers can do this work.

## Context and handoffs need less assembly

Gemini CLI 0.65.0 [leaves directory references for the agent to explore instead of eagerly reading the directory's files](https://github.com/google-gemini/gemini-cli/blob/v0.65.0/packages/cli/src/ui/hooks/atCommandProcessor.ts#L535-L549). Copilot CLI [adds structured workflow-child output in 1.0.101](https://github.com/github/copilot-cli/releases/tag/v1.0.101) and [passes existing custom/MCP approvals to children in 1.0.102](https://github.com/github/copilot-cli/releases/tag/v1.0.102). Codex 0.164.0 [overlaps eligible read-only calls](https://github.com/openai/codex/commit/c9e0fffbbc05c36478686444f6ab1edbadfe2768).

Those changes give an integration owner concrete replacements to try: directory packing, response parsing, grant reinjection and read scheduling. Name indispensable files explicitly, validate child results and exercise a denied child action. Structured output establishes a shape; it does not establish a correct answer. Codex's [full-history prefix preservation](https://github.com/openai/codex/blob/rust-v0.164.0/codex-rs/features/src/feature_configs.rs#L316-L319) supports context reuse, with a legacy-compaction exception, but proves no perpetual cache or quota guarantee.

The counterweight is context transformation itself. [Pi 1.4.0 still flattens typed roles into text before summarization](https://github.com/earendil-works/pi/blob/v1.4.0/packages/coding-agent/src/core/compaction/utils.ts#L120-L155). The [research's live Pi test used 0.79.0 and reported 3/6 poisoned cases against 0/5 controls](https://github.com/pixee/compaction-laundering/blob/9ce87b71301c628dfcd9232b01f1ccbdb0e67b16/disclosure/pi.md). It is a reason to verify a compacted claim of approval against the original instruction, not a current-version failure rate or a matched harness ranking.

## A resumed conversation and a recovered job are different promises

Codex 0.164.0 [records a summary only after compaction completes](https://github.com/openai/codex/blob/rust-v0.164.0/codex-rs/core/src/compact.rs#L858-L890) and [resumes compressed rollouts](https://github.com/openai/codex/commit/76ed3b484d62ccceb9fa512ff4dd139f421814c3). Claude Code 2.1.305 [uses its journal to avoid rerunning completed pipeline and parallel agents](https://github.com/anthropics/claude-code/releases/tag/v2.1.305). DeepSeek's rc SDK [restores saved history and the working directory](https://github.com/deepseek-ai/deepseek-harness/blob/1f81c047fc48fa190a683e469daa699857e9afe8/packages/sdk/client/README.md). These can replace conversation reconstruction and some restart glue.

Pi Durable 1.4 goes further in a particular direction: [a sleeping phase checkpoints and releases its invocation, while the host must persist the wake and reopen the harness](https://github.com/earendil-works/pi/blob/v1.4.0/packages/durable/README.md#L139-L220). Hermes [keeps classic CLI work running in the gateway after EOF or detach](https://github.com/NousResearch/hermes-agent/blob/v0.22.5/website/docs/developer-guide/gateway-classic-cli.md). Claude's [public-beta MCP Tasks contract](https://web.archive.org/web/20261024085041/https://code.claude.com/docs/en/mcp) gives eligible remote calls a server-owned task handle, with protocol, provider and session restrictions. An ordinary one-shot headless invocation does not acquire that behavior by updating the binary.

The next test is three tests: interrupt a summary, kill a process around a checkpoint/wake handoff, and interrupt a harmless external write. Keep the action identity and reconcile an unknown result before retrying. Claude 2.1.309 [explicitly reports interrupted remote tool outcomes as unknown](https://github.com/anthropics/claude-code/releases/tag/v2.1.309). A transcript cannot decide whether the external write happened.

Useful host machinery is growing alongside the reusable loop. [Paperclip stable preserves usage receipts until committed settlement](https://github.com/paperclipai/paperclip/blob/v2026.1023.0/server/src/services/run-cost-accounting.ts). [OpenHands ships a factory recipe with credentials and checkpoints](https://github.com/OpenHands/extensions/blob/v0.35.0/skills/software-factory/README.md). Neither is made redundant by a better summary. OpenCode's [optional background compaction lives in memory and can spend inference before it is needed](https://github.com/anomalyco/opencode/blob/v2.1.4/services/www/src/docs/content/compaction.mdx); put it in a latency experiment, not in the durable-execution column.

## The approval question now reaches the code host

Cursor's [16 October canvases launch](https://cursor.com/changelog/cloud-agent-canvases-and-environments) gives a cloud agent a shared object to deliver instead of making a person repackage its transcript. Origin's [current Code owner review contract](https://web.archive.org/web/20261024094000id_/https://cursor.com/docs/release-notes/origin.md) goes beyond presentation: Agentic can substitute Origin's ownership decision for the approval count, and an installed app can satisfy ownership review for its assigned paths. Keep Classic where a named person must approve.

Date that claim carefully. The note is labeled the week of 12 October, which spans the previous cutoff; its first publication is unknown. The [owning harvest's client comparison](../harvest/cursor.primary.md#16-origin-lets-an-agents-ownership-decision-or-an-installed-apps-approval-satisfy-code-owner-review) establishes added fields between sampled builds, while risk-rating machinery existed in the baseline. This is current capability established by the 24 October read, not a proved post-cutoff hosted launch.

The meaningful comparison is [Claude's hosted Code Review, generally available on 15 October](https://claude.dev/blog/solving-code-review-at-anthropic/). It [posts findings and a check without approving or blocking the PR](https://web.archive.org/web/20261017030656/https://code.claude.com/docs/en/code-review). Origin changes who may satisfy ownership review; Claude leaves that authority elsewhere. Count useful findings and overturned decisions separately from automated reviews. Origin also [accepts success, neutral and skipped conclusions for required checks](https://web.archive.org/web/20261024094330id_/https://cursor.com/docs/api/origin/reference/create-ruleset.md), making a prompt step's decision that work does not apply an acceptance-policy choice.

OpenClaw takes a different human gate away: [Workshop applies learned edits immediately and retains ten versions per skill](https://github.com/openclaw/openclaw/blob/v2026.10.7/docs/tools/skill-workshop.md). Review happens after a changed procedure can already affect work. Set `skills.workshop.autonomous.mode` to `off` when a person must initiate learning; manual learning remains available. The old pending-proposal recipe is gone. Bounded Undo is useful, but it does not measure the quality of learning or the burden of correcting it.

Elsewhere the gate gets stronger. [Codex 0.164.0 reassesses a Guardian-approved action when its retry requests escalation](https://github.com/openai/codex/blob/rust-v0.164.0/codex-rs/core/src/tools/orchestrator.rs#L484-L518). [OpenClaw binds review to final plugin-rewritten arguments](https://github.com/openclaw/openclaw/blob/v2026.10.7/src/agents/agent-tools.before-tool-call.policy.ts#L291-L436). [Claude 2.1.302 narrows some unconfigured headless auto defaults](https://github.com/anthropics/claude-code/releases/tag/v2.1.302), and [2.1.304 adds a person-only decision path that refuses when nobody can answer](https://github.com/anthropics/claude-code/releases/tag/v2.1.304). There is no common march toward fewer human decisions.

## Easier composition leaves a compatibility bill

Copilot's [1.0.100 local-network default](https://github.com/github/copilot-cli/releases/tag/v1.0.100) enables development loops against local services inside an enabled sandbox. It also exposes services the operator may have assumed were unreachable. Set `sandbox.allowLocalNetwork` deliberately and test both a needed server and an unintended private service. Sandbox enablement remains a separate, default-off choice. Its [released Assisted behavior for managed asks](https://github.com/github/copilot-cli/releases/tag/v1.0.100) still conflicts with the [enterprise promise of fresh approval without automatic shortcuts](https://github.com/github/docs/blob/02c25d16369fe27f9bdb28d1201f6b452f0d21dd/content/copilot/reference/enterprise-administrators/enterprise-managed-settings.md#L253-L261); inspect the decision maker in Manual and Assisted rather than inventing a resolution.

Wrappers also retain their own contracts. Paperclip stable's [remote Codex admission range is >=0.149.0 and <0.161.0](https://github.com/paperclipai/paperclip/blob/v2026.1023.0/server/src/services/native-runtime/codex-runtime-compatibility.ts). Standalone 0.164.0 falls outside it. OpenHands [offers Pi and OpenCode as local ACP engines](https://github.com/OpenHands/OpenHands/blob/v1.33.0/src/constants/acp-providers.ts), without establishing the installed native versions. Record the executable, package, server and adapter before importing a standalone profile's advice.

OpenCode [keeps old sessions readable while changing SDK, event and plugin contracts in 2.1](https://github.com/anomalyco/opencode/blob/v2.1.4/CHANGELOG.md#breaking-changes). Hermes [extracts its MCP server into a plugin and changes the client command](https://github.com/NousResearch/hermes-agent/blob/v0.22.5/hermes_cli/left_core_migration.py#L239-L278). A saved session or unchanged tool name can conceal a broken integration. These are costs to qualify, alongside real opportunities to remove duplicate plumbing.
