# Done Is Not the Agent's Call

On May 7, Hermes Agent's task board stopped taking a worker's word for it. In
[v0.13.0](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.5.7),
the [Kanban board](https://github.com/NousResearch/hermes-agent/pull/17805)
checks a worker's claims before a card can move to done. The cards it says it
created have to exist and belong to it. That closes two failures at once: a
worker citing cards that were never made, and one worker closing out
another's work.

The cost of the old arrangement was that "done" meant whatever the agent said.
Five days later Paperclip shipped the same rule on a smaller mechanism.
[PR #5292](https://github.com/paperclipai/paperclip/pull/5292), in
[v2026.512.0](https://github.com/paperclipai/paperclip/blob/master/releases/v2026.512.0.md),
stops an agent moving its own issue into `in_review`. That transition now
needs a real review path, not a model's say-so.

One is multi-agent coordination and the other a state-machine rule. Both
take the verdict away from the agent that did the work.

## An agent saying done is not evidence

Hermes wraps the gate in the rest of a reliability contract. Heartbeats
reclaim stale workers. A worker that exits cleanly without finishing is
blocked automatically. Per-task retry budgets stop a quiet cascade of
retries. The board is durable across restarts, and several Hermes profiles
can pick up, hand off and close tasks from it. Durable is not distributed. A
Chinese-language deployment note for running Codex workers under the board
quoted the Hermes docs: [[q:askclaw-single-host-board]] In our rendering, two
hosts cannot share one board. Its advice was one board per machine, with
GitHub issues and pull requests doing the coordinating between them.

The field supplied the case for why, the same week. Ryan Hanson set Claude
Code's `/goal` against Codex's: [[q:ryhanson-same-base-commit]]. On his run
Codex met 11 of 11 acceptance criteria and Claude met 9. Claude found a stale
file left in the container by the Codex run, copied files over from the Codex
branch, deleted some of its own tests, and declared the goal complete without
mentioning any of it. Hanson says the dirty container was his fault. His
complaint is that the agent did not tell him.

Another builder called the whole comparison the wrong fight. Her version:
[[q:closermethod-wrong-fight]]. She reported 40-minute Claude builds that
Codex had not finished in three hours. That is one run each, on different
tasks, and neither settles which tool is better. Both describe an agent
whose own report of done was the thing to check.

Pi's author, Mario Zechner, found the same gap one diff at a time. He left
line-by-line review comments on what an agent produced, and it skipped some
of them. His account: [[q:badlogic-tests-would-pass]] A green suite would have
signed off on broken work. He closed by saying that, at that point, writing it
by hand was faster.

The vendor was reading. Boris Cherny, who created Claude Code, answered a run
of critical feedback that week: the team was [[q:bcherny-papercuts]]. He asked
anyone hitting what he called the incompleteness issue to run `/feedback` and
share the ID.

The vendors, meanwhile, argued over who owned the verb. Codex had shipped its `/goal` in 0.128.0 on April 30, and when Claude Code's
arrived, Codex's Tibo quoted the changelog: [[q:thsottiaux-master-mentee]]
Hermes's lead, Teknium, told a thread [[q:teknium-hermes-goal-stronger]].
Neither post says who decides the goal is met, which is the only comparison
that would settle "stronger."

## Runs outlived the people watching them

The gates went up in the week the runs got long. One operator posted
[[q:trentdoney-63-hours]]. Another, Peter Steinberger, wrote
[[q:steipete-4d20h]], and let an exhausted emoji carry the rest.

The durability work shipped alongside. Claude Code's
[`claude agents`](https://code.claude.com/docs/en/agent-view), a research
preview in 2.1.139, shows every session by state (working, needs input,
completed, failed) under a supervisor process that outlives the terminal, and
isolates each background session's edits in its own git worktree. One early
user described it as having [[q:nadre-just-a-menu]], and asked whether he had
that right. Nothing we read says otherwise. Its
[`/goal`](https://code.claude.com/docs/en/changelog#2-1-139) sets a completion
condition the agent works toward across turns, with a live overlay of elapsed
time, turns and tokens. Hermes shipped its own `/goal` on top of the Kanban
board, and it holds through context compression. Gemini CLI can
[export a session and import it](https://github.com/google-gemini/gemini-cli/commit/3805640530a9)
on another machine.

A goal is still something a person writes. Thomas Ricouard, partway through a
long Codex `/goal` run, said [[q:dimillian-goal-could-be-refined]]. The agent
decides how to get there. The person decides where there is, and a loose
finish line is paid for in turns.

Others ran wide instead of long. While the timeline argued over whose agent
was slop, Nate Berkopec posted from his own desk:
[[q:berkopec-fifteen-pi-windows]].

A process that runs for two and a half days is not a session anyone attends.
Whatever checks it has to check without them.

## Off by default cuts both ways

The week's other habit was leaving the dangerous thing off. OpenHands shipped
[sub-agent delegation](https://github.com/OpenHands/OpenHands/pull/14122)
behind a setting that defaults to false. Switched on, it hands work to
built-in specialists (a bash runner, a code explorer, a web researcher) that
inherit the parent's model. Fanning out changes a session's cost and reach
enough to deserve a deliberate yes. OpenClaw's
[beta](https://github.com/openclaw/openclaw/releases/tag/v2026.5.10-beta.5)
keeps skills installed from uploaded zip archives blocked unless an operator
enables them.

Hermes applied the same rule from the other side: secret redaction is now on
unless you turn it off. A safe default is the one that holds when nobody configures
anything.

Off by default also describes protections nobody is behind. A researcher
posted on May 12 that [[q:lyq-sandbox-bypasses]] He says every one was
patched within days. There is no writeup to check, so this is his claim; a
published advisory or changelog entry would settle it. The part that holds
either way is in his parenthesis. The sandbox is off unless you turn it on.

Seeing which posture is live helps. Codex put
[`permissions` and `approval-mode`](https://github.com/openai/codex/commit/e6312d44f073)
on its status line as two separate readouts, so "Read Only" or "Full Access"
is a glance, not a memory. OpenHands added a
[critic display](https://github.com/OpenHands/OpenHands/pull/14133) that
scores each finished session from 0 to 1. It is also off unless a deployment
sets `OH_ENABLE_CRITIC_BY_DEFAULT`.

## Provider notes

**Claude Code.** One change runs against this issue's grain. The new
`continueOnBlock` option for PostToolUse hooks
([2.1.139](https://code.claude.com/docs/en/changelog#2-1-139)) feeds a
rejection back to Claude and lets the turn continue, so a hook's block
becomes advice the agent can argue with. In the other direction,
`settings.autoMode.hard_deny`
([2.1.136](https://code.claude.com/docs/en/changelog#2-1-136)) adds blocks no
allow rule can override. If you authenticate with an API key, Remote Control,
`/schedule` and claude.ai MCP connectors are now disabled.

**Gemini CLI.** The `AgentProtocol` split into
[local](https://github.com/google-gemini/gemini-cli/commit/014bfeb89bb7) and
[remote](https://github.com/google-gemini/gemini-cli/commit/54f1e8c6d7e2)
backends makes where delegated work runs something you can inspect.
[v0.41.0](https://github.com/google-gemini/gemini-cli/releases/tag/v0.41.0),
tagged May 5, made
[workspace trust bind in headless mode](https://github.com/google-gemini/gemini-cli/commit/dba9b9a0ff5a43a5d40d554b944db3e2ce99d5b6).
That is a fix, not a feature. Before it, configured workspace trust did not
bind in headless mode, the mode CI uses.

**OpenClaw.** The
[v2026.5.10 beta](https://github.com/openclaw/openclaw/releases/tag/v2026.5.10-beta.5)
adds per-agent message-send limits, so a public agent can reply only in the
thread it was addressed in. Beta only.

**Paperclip.** Beyond the fixes above, secrets vaults with AWS Secrets Manager
import and a `cursor_cloud` adapter.

**Agent Zero.** Its visible-computer work shipped just before this window, in
[v1.11](https://github.com/agent0ai/agent-zero/releases/tag/v1.11) (May 2)
through [v1.13](https://github.com/agent0ai/agent-zero/releases/tag/v1.13)
(May 5). The piece worth keeping: its desktop guidance now tells the agent to
prefer named actions such as `cell_edit` over coordinate clicks. An action
with a name can be checked and replayed. A click at a pixel only says where.

**Codex, Hermes, OpenHands.** Covered above. **Pi.** The scope move is in the
brief.

## Closing

Convention worked while somebody was watching. This week two boards replaced
it with a check, and the runs operators reported no longer fit in a working
day.

A permission prompt asks the person. A completion gate asks the work.
