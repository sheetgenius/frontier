# Auto Stops Asking

On 27 May Claude Code shipped
[2.1.152](https://code.claude.com/docs/en/changelog#2-1-152), and one line in
it removed a click. Auto mode, the classifier that runs the actions it judges
safe and stops on the ones it judges risky, no longer asks for opt-in consent.
It is the default posture.

The click was never much of a control. It was a visible one. Some admins
treated that dialog as the moment an operator confirmed, knowingly, that the
agent could act first and report after. That moment is gone, and the changelog
does not say what Auto mode now classifies as safe. The only complete list is
the runtime's behaviour.

Claude Code was not alone. Codex made goal mode the default, and Gemini CLI
collapsed its Auto variants and began auto-approving shell redirects. Autonomy
became the thing you opt out of. In the same fortnight three projects moved the
decision the click used to carry into a file.

## What each default actually turned on

The three flips are not the same flip, and the differences are where the
operator decisions hide.

Claude Code's is the broad case: a runtime classifier draws the line between
safe and risky, and nobody wrote the line down. The same release handed authors
two levers pointing opposite ways. A skill's `disallowed-tools` field subtracts
from what the agent can do. A new `MessageDisplay` hook can rewrite or hide
assistant text before the operator reads it. One narrows the agent. The other
narrows the human.

Codex's is the long-horizon case. The
[26.519 launch](https://developers.openai.com/codex/changelog) on 21 May took
goal mode out of experimental across app, IDE and CLI, and
[CLI 0.133.0](https://github.com/openai/codex/releases/tag/rust-v0.133.0)
turned goals on by default, with their own storage and progress tracking. You
can hand Codex an objective measured in "hours or even days" and walk away. The
same launch let Codex drive a Mac after the screen locks, behind short-lived
authorization, covered displays and a relock on any local input. Those are
sensible safeguards. They are policy, not a wall.

Gemini CLI's was the quietest.
[Stable v0.44.0](https://github.com/google-gemini/gemini-cli/releases/tag/v0.44.0)
folded a fan of Auto variants into one mode, billed as simplification, and
whatever distinctions the variants carried went with them. It also began
auto-approving shell redirects (`>`, `>>`, `|`) in `AUTO_EDIT`. That is a
convenience right up until an agent is steered toward a path it should not
write.

The benefit and the bill arrive together. [Amdahl Maxing](/amdahls-law/) means
spending scarce human attention where it has the highest marginal value, and a
consent dialog clicked by reflex is not that place. Removing it can be right. But an operator who used the dialog as a last look before something
irreversible now has to rebuild that look somewhere else: managed settings, a
hook, or review out of band.

The speed is free. The checkpoint is not.

## The decision moved into a file

Once an agent runs by default, the question is no longer whether it may act but
within what bounds, and bounds do not belong in a flag that lives for one
session. Three projects said so in the same fortnight.

Codex went furthest. CLI 0.133.0 let a
[permission profile inherit](https://developers.openai.com/codex/changelog)
from a base and layer changes on top, and paired it with a managed
`requirements.toml` the release calls enforcement, not advice. CLI 0.134.0 made
`--profile` the single selector across the CLI, its terminal UI and the sandbox,
and started rejecting the old flag configs outright.

Gemini CLI cut narrower and deeper. It pushed its
[PolicyEngine into ACP sessions](https://github.com/google-gemini/gemini-cli/issues/27252).
The changelog files that as a deadlock fix, which undersells it: enforcement now
reaches the protocol layer the docs hold up as the way to delegate work.

OpenHands showed the same move with the schema visible. Its
[org-level LLM profiles](https://github.com/OpenHands/OpenHands/pull/14406) are
an encrypted column on the organization table, six endpoints under
`/api/organizations/{org_id}/profiles`, and a two-role split: one role reads
settings, another creates, edits and activates them. Activation flips the org's
live profile and the acting member's settings in one locked transaction. The
database is admitting that "which policy is in force" is contested, shared state
worth serializing.

For anyone running a team the advice is the same across all three. Write a
base, derive the per-team variations, and check the file in. What none of the
three has documented is how that file reaches a machine and whether it is
signed. Close that gap before you call it enforcement.

## The gate went where the input crosses

The fortnight's sharpest thread ran through three projects working on unrelated
parts of the stack. Each put a structural gate at the spot where untrusted input
enters, rather than asking the model to behave once the input is already inside.

[OpenClaw](https://github.com/openclaw/openclaw/releases/tag/v2026.5.26) put
its gate where messages arrive. Sender allowlists now run before the agent is
dispatched, not after. Browser snapshots check SSRF policy before reading a
tab's URL. Queued system text is scrubbed so a hostile plugin or channel label
cannot forge the markers the model reads as instructions. An unauthorized
sender gets no chance to shape the agent at all.

[Agent Zero](https://github.com/agent0ai/agent-zero/releases/tag/v1.17) put its
gate where actions land. The new `computer_use_remote` tool drives the
operator's real desktop, outside the container, through the platform's
accessibility APIs, and it refuses to trust its own work. A state-changing
action stays unverified until a fresh screenshot confirms it, and with no
screenshot the agent must stop. A denied approval on macOS has to be re-armed
by hand.

[OpenHands](https://github.com/OpenHands/OpenHands/pull/14528) put its gate
between tenants, because credentials had been crossing. Until the fix, an MCP or
`acp_env` setting added by one member of an organization was written to every
member's row. Agent settings now split into a shared half and a private one,
secrets follow only the member who set them, and leaked values are stripped on
read.

A prompt asks the model to keep bad input out. A gate at the boundary does not
ask.

## What got within reach

The fortnight did not only add fences. OpenHands, with `ENABLE_ACP` set, now
fronts Claude Code, Codex or Gemini CLI as the agent behind its own UI, greying
out its own model and MCP settings because the wrapped agent owns them.
Paperclip's ACPX-Claude adapter goes one step further in deference: it respects
the operator's own `~/.claude/settings.json` permissions, the window's one case
of a wrapper obeying the wrapped tool's rules.

Hermes v0.14.0 became something you can
[`pip install`](https://github.com/NousResearch/hermes-agent/pull/26593), with a
native Windows beta and a cold start about 19 seconds shorter. Its new
[`hermes proxy`](https://github.com/NousResearch/hermes-agent/pull/25969)
exposes a local OpenAI-compatible endpoint backed by whichever OAuth provider
you are signed into, so Codex CLI, Aider, Cline or Continue can run on one
subscription. The PR binds it to `127.0.0.1` by default and says the proxy does
not authenticate local callers. Anything on the machine that can open a
loopback socket can spend your subscription.

## Breaking changes and security notes

**Claude Code 2.1.147 to 2.1.149.** In
[2.1.149](https://code.claude.com/docs/en/changelog#2-1-149), PowerShell's
built-in `cd..`, `cd\`, `cd~` and `X:` no longer move the working directory past
the workspace boundary undetected, and the git-worktree sandbox write allowlist
no longer covers the whole main repository root instead of the shared `.git`.
[2.1.147](https://code.claude.com/docs/en/changelog#2-1-147) makes
`forceLoginOrgUUID` and `forceLoginMethod` enforce against third-party-provider
and API-key sessions, and
[2.1.148](https://code.claude.com/docs/en/changelog#2-1-148) closes a Vertex AI
provider bypass. The changelog is the only place any of this appears.

**Hermes v0.14.0** removes the `[all]` extras. Heavy adapters install lazily on
first use, so a backend can be missing until something calls it.

**OpenClaw** turns on a gateway auth rate-limiter for any config that never set
`gateway.auth.rateLimit`. Monitoring built on the old auth-failure behaviour
needs adjusting.

## Provider notes

**Codex (26.519; CLI 0.131 to 0.134)** ran the window's most coordinated
release train. Goal mode's graduation and the CLI default landed the same day as
profile inheritance and the managed requirements file. Capability and its
governance shipped as one move, which nobody else managed this fortnight.

**OpenClaw (v2026.5.18 to v2026.5.26)** put its weight where its risk is:
content-boundary hardening and reaction-based approvals across Signal, iMessage
and WhatsApp. Its releases now carry verification stanzas with full CI run URLs,
a vendor showing its receipts.

**Paperclip (v2026.513, v2026.517, v2026.525)** built scoped agent permissions
on a real authorization service rather than a convention.

**Pi (v0.74.1 to v0.76.0)** and **Hermes Agent** both went after the supply
chain: npm shrinkwrap and lifecycle-script controls in Pi, an advisory checker in
Hermes.

**OpenHands** tagged nothing in the window. Everything above is on main.

**Gemini CLI (v0.44.0)** made its local and remote session-invocation protocols
stable.

**Agent Zero (v1.15 to v1.18)** also lets an operator hide skills from the
model-facing catalog.

**Flue (v0.6.0 to v0.8.0)** split persistent `agents/` from finite
`workflows/`, and runs are now a workflow-only concept.

## The click was the decision

Three makers moved the permission ceremony from something you opt into to
something you opt out of. The decision it carried did not disappear. It moved
into a policy file.

That is an improvement: a file is versioned, reviewable, and outlasts anyone's
attention span. It is also a new way to be wrong quietly. A click is a decision
a person made. A file is a promise a runtime has to keep.

Test the file. It is the only part of this that can fail without telling you.
