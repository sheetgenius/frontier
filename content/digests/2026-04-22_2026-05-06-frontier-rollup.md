# Only One of Them Asks

On April 30, Hermes Agent gave the agent an employee.
[Curator](https://github.com/NousResearch/hermes-agent/blob/v2026.4.30/RELEASE_v0.12.0.md#L58-L64),
shipped in [v2026.4.30](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.4.30),
is a background process that grades, consolidates and prunes the agent's skill
library on a default seven-day cycle. It keeps bundled and hub skills behind
gates, and it writes a run log and a `REPORT.md`. It runs on its own schedule.
You find out what the agent stopped knowing by reading the report afterwards.

The same day, Codex CLI
[0.128.0](https://github.com/openai/codex/releases/tag/rust-v0.128.0) made
[`/goal`](https://developers.openai.com/codex/changelog/#github-release-315916672)
a first-class surface: a persistent objective with its own app-server APIs,
model tools and terminal controls to create, pause, resume and clear it. A
prompt dies with its window. A goal outlives sessions, interruptions and the
operator's attention.

So the question changes. Not whether the agent can remember. It can. What it
remembers, and who decided that is still the right thing to pursue.

## A goal is memory with authority

Three more tools shipped state of their own, and the differences matter more
than the trend. Claude Code added
[automatic session recaps](https://code.claude.com/docs/en/interactive-mode#session-recap):
come back to a terminal you left and the agent tells you, in one line, what
happened while you were gone. That is a summary. It informs you and decides
nothing.

Gemini CLI, in a
[preview build](https://github.com/google-gemini/gemini-cli/blob/v0.42.0-preview.0/docs/changelogs/preview.md#L70-L72),
is testing an Auto Memory inbox in which memory arrives as a canonical patch:
proposed, reviewed, accepted. Nothing enters the agent's context until you say
yes. Of everything in this issue that writes to what the agent knows, it is
the only one that asks first.

On May 6, Anthropic put a research preview of the other approach in front of
everyone: [[q:claude-dreaming-preview]]. Like Curator, it runs between
sessions, and nobody is asked.

Asking has a price. [Amdahl Maxing](/amdahls-law/) means spending scarce human
attention where it has the highest marginal value, and a review prompt on every
memory write spends it constantly. But memory is the one input that shapes
every later run. If a human reads anything, a patch to what the agent will
believe next week is a strong candidate. Gemini pays that price. Curator
leaves a report afterwards, and the dreaming announcement describes no review
step at all.

Put `/goal` beside these and the fortnight has a shape. A serious run can now
be steered by a standing goal, a recap, an accepted memory patch and a skill
a background process chose to keep. None of it shows in the prompt you read.
The surfaces are good. Keep the record of what touched the run in something
the agent does not own.

## The leash got longer on the same day

On May 6, Anthropic doubled Claude Code's five-hour rate limits and removed the
peak-hour reduction:

<!--card:claude-limits-doubled-->

The same day, Paperclip said its users could now
[[q:paperclip-12-hour-runs]]. That is the vendor's description, not our
measurement. But a twelve-hour delegated run is the practical reason goals,
recaps, memory patches and curators exist. Nobody watches a transcript for
twelve hours. The state layer is what you install when the work outruns your
attention, and the work got room to run longer on the day the state layer
filled in.

## Permission got clearer and stopped translating

Codex 0.128.0 expanded
[permission profiles and sandbox profile selection](https://github.com/openai/codex/releases/tag/rust-v0.128.0),
with active-profile metadata so a run can say which profile governed it.
Gemini CLI [v0.41.0](https://github.com/google-gemini/gemini-cli/releases/tag/v0.41.0),
published May 5, added
[secure `.env` loading and workspace trust in headless mode](https://github.com/google-gemini/gemini-cli/blob/v0.41.0/docs/changelogs/preview.md#L37-L38),
plus
[shell command validation and a core-tool allowlist](https://github.com/google-gemini/gemini-cli/blob/v0.41.0/docs/changelogs/preview.md#L35-L36).

The headless-trust item is a repair, not a feature. Before v0.41.0, configured
workspace trust did not bind in headless mode, which is the mode continuous
integration uses. If your CI ran an earlier Gemini CLI, the trust settings you
wrote were not the ones it used.

Claude Code kept reworking its
[permission prompts, plugins, hooks and MCP surfaces](https://code.claude.com/docs/en/changelog#2-1-118).

More visible authority is progress. The cost is that "profile", "trust",
"allowlist" and "sandbox" name different mechanisms in each tool, and none of
them translates. "The agent had access" was never an answer. What it could
read, change, execute and install is, and this fortnight made that easier to
find out and harder to compare.

## The review now ships inside the harness

Claude Code's Week 17 notes introduced
[`/ultrareview`](https://code.claude.com/docs/en/ultrareview), a research
preview that sends a cloud fleet of bug-hunting agents at a branch or pull
request and returns the findings to
[Claude Code and Desktop](https://code.claude.com/docs/en/whats-new/2026-w17).
A tool that can criticize its own work is worth wanting.

Hold the line between evidence and verdict. A native review can say "this
path looks risky". It cannot say what done means, because the project owns
that standard and the provider does not. Before a fleet's findings feed
anything, run it on a branch you already reviewed and see where it disagrees
with you.

## Provider notes

**Pi.** The fortnight's argument against treating an integration list as
architecture. Across
[five releases](https://github.com/badlogic/pi-mono/blob/v0.73.0/packages/coding-agent/CHANGELOG.md#L3-L9)
it added DeepSeek, Cloudflare Workers AI, Moonshot, Mistral, Azure and Xiaomi
MiMo providers, moved Codex to a
[cached websocket transport](https://github.com/badlogic/pi-mono/blob/v0.73.0/packages/coding-agent/CHANGELOG.md#L25-L31),
added
[provider retry and timeout controls](https://github.com/badlogic/pi-mono/blob/v0.73.0/packages/coding-agent/CHANGELOG.md#L198-L209),
and
[removed built-in Gemini CLI and Antigravity support](https://github.com/badlogic/pi-mono/blob/v0.73.0/packages/coding-agent/CHANGELOG.md#L68-L79).
If a run depended on a provider or a transport, record it. Pi removed two
this fortnight.

**Codex.** 0.128.0 is the release to read. It also shipped
[plugin marketplace workflows and bundled hooks](https://github.com/openai/codex/releases/tag/rust-v0.128.0),
so more of what a Codex run can do now lives in attachments.

**Claude Code.** Recaps and `/ultrareview` are above. Most of the rest was
plugin distribution, theming, and MCP and hook fixes.

**Gemini CLI.** The memory inbox exists in preview and not in stable, so
"Gemini CLI" is not a complete description of a run. Record the channel.

**Hermes Agent.** Curator is above. The earlier
[v2026.4.23](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.4.23)
rebuilt the CLI around React/Ink and made transports pluggable.

## Closing

The layer around the agent now makes decisions: which goal stands, what gets
remembered, which skill survives the week. That is useful, and it is
invisible by default.

Several processes now decide what the agent knows. One of them asks.
